# Origin

Origin is an early-stage Android project for exploring how things work, connect,
and originate. The current release provides the Kotlin and Jetpack Compose
application foundation; product features will follow in later versions.

## Build

The project requires JDK 17 and the Android SDK 37 platform. From the repository
root, run:

```sh
gradle assembleDebug
```

The debug APK is written to `app/build/outputs/apk/debug/`.
